## Description

- Товарные страницы: `Фреон R{код} в баллонах. Цена от объема, документы по запросу, самовывоз и доставка по России.`

- Оплата: `Расчет, счет, договор при необходимости и отгрузка после поступления оплаты.`
- О компании: `РусХимСоюз поставляет фреоны для закупок по России. Документы на товар по запросу.`

## Миграция URL

Использовать карту 301-редиректов из `../home/seo-map.md`. Важные соответствия: старые `/tovar/freon-*` ведут на одноименные `/products/freon-*`; `/doc/freony` → `/articles/freony`; старая статья R404A → `/articles/freon-404a-primenenie`; старый R12 → `/articles/freon-r12`.

## Микроразметка

- Все внутренние страницы: `BreadcrumbList` с видимыми хлебными крошками.
- Товарные страницы: `Product` только после загрузки в CMS видимых цены, валюты, веса, фото, статуса наличия и URL товара.
- Страницы с FAQ: `FAQPage` только для вопросов, видимых в основном контенте.
- Блоговые статьи: `Article` после подтверждения автора и даты публикации. Не использовать выдуманные даты или автора.
- `Organization` и `WebSite` использовать из `../home/seo-map.md`.
