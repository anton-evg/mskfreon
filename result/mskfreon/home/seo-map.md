## Перенос старых URL

Настроить постоянные 301-редиректы. Старый текст не удаляется: его смысловой и технический контент переносится на новую целевую страницу.

| Старый URL | Новый URL | Действие |
|---|---|---|
| `/kompaniya-ooo-mskfreon-krupneyshiy-postavshchik-freona-moskvy-i-rf-my-garantiruem-luchshie-ceny` | `/` | 301 |
| `/o-kompanii` | `/about` | 301 |
| `/dostavka-freona-po-moskve-i-v-regiony` | `/delivery` | 301 |
| `/articles` | `/articles` | Сохранить URL |
| `/tovar/freon-134` | `/products/freon-134` | 301 |
| `/tovar/freon-404` | `/products/freon-404` | 301 |
| `/tovar/freon-407` | `/products/freon-407` | 301 |
| `/tovar/freon-410` | `/products/freon-410` | 301 |
| `/tovar/freon-22` | `/products/freon-22` | 301 |
| `/tovar/freon-r507` | `/products/freon-507` | 301 |
| `/tovar/freon-r600` | `/products/freon-600` | 301 |
| `/tovar/freon-r12` | `/articles/freon-r12` | Создать статью, затем 301 |

Дополнительно перенаправлять варианты этих URL со слешем в конце на канонические адреса без слеша. Старый URL страницы контактов не указан: его нужно установить по старому сайту или данным Search Console (Google Search Console — панель данных индексации), затем добавить в таблицу.

## Требования к SEO-реализации

- На каждой странице один H1.
- Указывать self-canonical без параметров.
- Не создавать цепочки редиректов.
- Сохранять параметры запроса при редиректе, если они нужны аналитике.
- Добавить все канонические URL в `sitemap.xml`.
- Старый контент из `content-pages.md` переносить в соответствующие страницы: с редактурой формата, но без потери тематических разделов, характеристик, применения, тары, транспортировки и хранения.
- Не размечать динамические цену и наличие, пока они не выводятся в видимом контенте и не управляются CMS.
