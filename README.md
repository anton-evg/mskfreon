# mskfreon.ru

React-сайт компании ООО «РусХимСоюз».

## Запуск

```powershell
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite, обычно `http://localhost:5173/`.

## Производственная сборка

```powershell
npm run build
npm run preview
```

Готовая сборка создается в каталоге `dist`.
